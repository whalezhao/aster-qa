# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith, and keep technical discussions focused on the
problem. Harassment, discrimination, and personal attacks are not welcome.

Instances of unacceptable behavior can be reported privately to the maintainers
through the GitHub account shown in the repository metadata. Reports will be
reviewed and handled confidentially.
