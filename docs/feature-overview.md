# Aster QA 功能总览

AI 驱动的测试用例与回归管理平台：从需求/功能到用例、执行、报告、AI 诊断，一条链路走完。

## 1. 测试资产与组织

- **测试团队**：多团队隔离，成员角色分为 owner / admin / member。
- **项目（系统）**：每个项目独立配置被测地址、模型、环境、测试文件和数据库。
- **功能树**：支持多级子功能；功能带需求编号（禅道 / Jira）。
- **迭代管理**：按迭代组织功能和用例。
- **标签**：跨功能给用例和任务打标签。
- **功能分期**：当前迭代 / 正式；支持单个或批量转正式、回退。
- **用例资产**：用例名称、描述、优先级 P0–P3、缺陷编号、启停状态、独立分期。
- **用例 YAML**：一份用例就是一个可执行的 Aster QA 脚本文档。
- **用例列表**：按功能查看、搜索、排序和导出 Excel。

## 2. AI 用例生成与维护

- **AI 生成用例**：自然语言对话直接产出可执行 YAML，流式输出。
- **AI 迭代用例**：在已有用例上继续对话修改，支持改写和续写两种模式。
- **AI 修复用例**：读取真实失败步骤和错误，生成修改后的 YAML 和 diff，人工确认后保存为新版本。
- **用例版本历史**：创建、保存、AI 修复、回滚都留快照，可查看 diff、可回滚。
- **执行版本绑定**：执行记录绑定当时真正执行的 YAML 版本，不会跳到最新版本。
- **步骤可视化编辑**：步骤与 YAML 逐行对照，支持拖动列宽、目录定位、单步试跑。
- **步骤字段编辑**：上传、下载、数据库比对、记录变量等节点都有对应可视化字段。
- **YAML 校验**：保存和执行前校验结构、节点字段和变量引用。
- **XPath 辅助生成**：对话里给出 XPath 时，AI 会把 XPath 写进单元素动作节点的 `options.xpath`。
- **精准定位回退**：XPath 命中时优先使用，未命中自动回退到自然语言定位。

## 3. 环境与测试数据

- **多环境**：一个项目可配置开发 / 预发 / 生产等多套环境，各自独立 Base URL。
- **任务按环境执行**：同一次任务可以勾选多个环境，每个环境生成一条执行记录。
- **普通变量**：YAML 里用 `${KEY}` 引用。
- **密钥变量**：YAML 里用 `${{KEY}}` 引用，数据库加密存储，只注入执行进程。
- **随机变量**：环境变量可设为固定值、随机字符串或随机数字，并设置长度。
- **测试文件库**：按环境上传图片、PDF、Excel 等测试文件。
- **按 key 引用文件**：用例用 `upload` 节点按 key 引用文件，同一个 key 在不同环境可指向不同文件。
- **下载节点**：等待浏览器下载、校验文件名和大小，下载产物保留在执行记录里。
- **数据库数据源**：按环境配置 MySQL、OceanBase（MySQL 模式）、PostgreSQL 只读连接。
- **数据库比对**：`dbAssert` 节点把页面取值和数据库列值做精确或带容差比较。
- **数据源安全**：数据库密码加密存储，只注入执行子进程，不写进 YAML、配置或报告。
- **登录会话复用**：在环境中指定登录用例和可选检查用例，执行时复用浏览器登录状态。
- **会话失效恢复**：登录状态失效时自动重新登录，并可选择自动重试失败用例。

## 4. 测试任务

- **任务快照**：任务创建时把功能、用例、编排快照下来，之后源功能变化不影响已建任务。
- **精确选用例**：可以选整个功能，也可以只勾单条用例。
- **跨项目任务**：一个任务可以包含多个系统的用例，执行时自动拆成多个 run。
- **单项目分片**：按「单 run 用例数」把用例切成多个 run 并行执行。
- **套用编排**：创建任务时可以直接套用可复用的用例编排。
- **保存后立即执行**：创建任务时可以直接触发第一次执行。
- **任务列表筛选**：按系统、分期、状态、任务名、创建人筛选。
- **我的任务**：一键只看自己创建的任务。
- **创建人字段**：任务列表显示创建人和创建人筛选。
- **创建人管理**：创建人可以编辑、删除自己创建的任务；团队 owner / admin 可管理全部任务。
- **执行任务**：手动选择环境执行，支持多环境各建一条执行记录。
- **快速多任务执行**：勾选多个任务依次触发。
- **批量删除**：批量删除任务及其执行记录；无权限或正在执行的任务会被跳过并说明原因。
- **定时回归**：每个任务一条 cron 计划，支持时区、重叠跳过和失败通知。
- **任务签名**：对任务用例集做内容指纹签名，用例变更后自动标记「已过期」。

## 5. 执行与编排

- **用例依赖编排**：项目级可复用编排模板，可以跨功能选用例并设置前置依赖。
- **按依赖执行**：编排内的用例按 DAG 依赖顺序执行，无依赖的分支并行。
- **前置失败传播**：前置失败或阻塞时，后续节点标记为「被前置阻塞」，并按失败计入统计。
- **未编排用例并发**：未加入编排的用例仍按原有分片并发执行。
- **编排图编辑器**：图和表格两种视图，节点可拖动、连线、自动布局，位置会保存。
- **编排版本历史**：每次保存 / 回滚生成版本，可查看历史并回滚；已套用任务不受影响。
- **任务编排页**：在任务详情里套用编排、查看 DAG、调整任务内依赖。
- **节点数据传递**：`capture` 节点从页面或数据库取值，下游节点用 `${变量名}` 引用。
- **条件分支**：节点可设置等于、不等于、包含、大于、小于条件；不满足时跳过该节点及下游。
- **固定循环**：节点可设置重复次数，按顺序执行多轮，前一轮输出传给下一轮。
- **重跑失败/阻塞子图**：只重跑失败或阻塞的节点，已成功的前置不重跑。
- **直接运行编排**：不建任务也可以直接运行一个编排。
- **调试试跑**：从任意一步开始试跑用例，快速验证后续步骤。
- **取消执行**：取消排队中的节点，运行中的节点在当前用例结束后停止。
- **删除执行**：删除批次、run、报告和本地产物；正在执行的批次不能删。
- **执行器监控**：查看 worker 在线状态、槽位和心跳。

## 6. 执行记录与报告

- **四级下钻**：批次 → run → 用例 → midscene 报告。
- **批次视角**：一次执行跨多个系统也只算一件事。
- **执行人字段**：执行记录显示执行人，并可按执行人筛选。
- **我的执行**：一键只看自己触发或执行过的记录。
- **执行筛选**：按系统、分期、任务名、执行人筛选。
- **每个功能的通过情况**：一行里直接看到这次执行各功能过没过。
- **用例级报告**：步骤带关键帧时间线、回放、参数、输出、日志和推理过程。
- **AI 执行评估**：读取真实失败证据，给出根因、责任归属和逐条建议；全绿批次不调模型。
- **非用例失败排除**：模型额度、模型服务、网络等非用例原因导致的失败不计入通过率。
- **下载产物**：执行中下载的文件保留在详情页。
- **结构化报告**：提供结构化数据，前端还原完整报告能力。

## 7. 合规、质量与统计

- **合并执行报告**：一次执行跨多个项目时，把各 run 报告合并成一份正式报告。
- **打印 / PDF**：正式报告支持打印和导出 PDF。
- **电子签章**：按执行记录签章，一次只签一条执行记录；报告内容变更后原签章失效。
- **人工签名**：对任务用例集生成内容指纹签名，用例变更后自动提示过期。
- **质量门禁**：按最低通过率、P0 失败策略给 CI 返回门禁结论。
- **通过率统计**：整体通过率、Wilson 置信下界、首次通过率。
- **Flaky 榜单**：识别反复失败的用例。
- **Token 用量**：按项目和模型统计 token 消耗。
- **需求覆盖矩阵**：按需求编号查看用例覆盖情况。
- **团队复盘**：AI 汇总一段时间内的执行情况并给优化建议。

## 8. 自动化与集成

- **CI 触发**：团队 API Token 触发任务执行、查询批次状态。
- **执行前预检**：模型连通性、环境、额度、被测地址、执行器在线状态一次看清。
- **Webhook**：`task.signed`、`batch.completed`、`batch.assessed`、`quality_gate.failed`、`schedule.failed`、`model.unhealthy`。
- **Webhook 安全与重试**：HMAC 签名 + 指数退避重试。
- **通知渠道**：通用 Webhook、企业微信、飞书、钉钉、Slack。
- **模型健康巡检**：定期检查项目模型连通性，结果用于项目徽标和预检。
- **项目级模型配置**：每个项目独立配置模型名、模型族、接入地址和 API Key，没有全局兜底。
- **Token 限额**：按项目设置每月 token 限额，超限后拦截执行和 AI 调用。

## 9. 平台与使用体验

- **登录与账号**：账号登录、修改密码、人员维护、停用账号。
- **团队与成员**：团队创建、成员邀请、角色调整、移除成员。
- **深浅色主题**：浅色 / 深色模式。
- **中英文界面**：界面语言切换。
- **AI 助手**：页面内的 AI 形象、提示气泡和语音朗读。
- **版本公告**：顶栏新版本红点、公告抽屉和完整历史页。
- **执行产物保留**：按保留天数和每个任务保留批次数自动清理。
- **数据与产物解耦**：删产物不影响统计，删任务会连带清理执行记录。
- **Docker Compose 部署**：web / api / worker / postgres 一键启动。
- **多 worker 扩容**：通过 worker 副本和全局并发上限水平扩容。
- **数据库迁移**：API 启动自动执行 Alembic 迁移。

## 10. 权限与协作

- **团队隔离**：不同团队的数据默认不可见。
- **角色权限**：owner / admin / member 分层。
- **任务归属**：任务显示创建人，创建人可以管理自己的任务。
- **执行归属**：执行记录显示执行人，便于按人筛选和审计。
- **签名追溯**：人工签名、电子签章都记录签名人和时间。
